One out-of-office auto-reply, at most 120 characters, written as if a houseplant sent it — built for [make.fun](https://make.fun)'s "The Houseplant Out-of-Office" bounty ($2 in USDC).

The reply: a fern that has not been watered since March and is thriving on spite alone. Its own neglected life drives the joke, and the punch lands on the last words.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt`.
